# 2.2.0

## Нове

- **«Try it out» з Документації API (2026-11-26).** Swagger UI на `https://api-docs.kub.k2.lan` тепер може сам
  викликати ендпоінти шлюзу з браузера людини. Шлюз відповідає CORS лише одному точному origin з нової змінної
  `API_DOCS_ORIGIN` (у `deploy.yaml` — `https://api-docs.kub.k2.lan`):
  - `Access-Control-Allow-Origin: <цей origin>`, `Access-Control-Allow-Credentials: true`, `Vary: Origin`;
  - preflight `OPTIONS` → 204: методи `GET, POST, OPTIONS`, заголовки
    `content-type, authorization, x-csrf-token, x-requested-with`, `Access-Control-Max-Age: 600`;
  - лише маршрути API (повідомлення, чати, сесія, health, `/qr`), з `PATH_BASE` і без нього; сторінки Swagger UI
    (`/docs`, `/docs/…`) і `/openapi.json` CORS не отримують;
  - будь-який інший origin (зокрема схожі: інша схема, порт, суфікс домену) не отримує жодного CORS-заголовка.
    Ні `*`, ні шаблонів, ні віддзеркалення.
  - Порожня змінна — CORS немає, як і раніше.
- Ендпоінти шлюзу, як і досі, без токена. CSRF-захисту чи перевірки Origin у шлюзі немає, кукі він не ставить
  і не читає, тож нічого з цього не змінилося.
